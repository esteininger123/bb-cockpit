B&B Cockpit verbinden

Damit das Cockpit deine echten Airtable-Zahlen zeigt, brauche ich einen Personal Access Token mit Lese-Recht auf die Objektmanagement-Base. Den Token musst du nur einmal eintragen — er bleibt auf diesem Gerät gespeichert.

So bekommst du den Token:
1. airtable.com/create/tokens öffnen
2. Name: „B&B Cockpit FireTV" · Scope: data.records:read
3. Access: nur Base „Objektmanagement"
4. Token kopieren und hier einfügen
